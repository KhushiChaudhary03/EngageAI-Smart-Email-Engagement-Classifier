# EngageAI-Smart Email Engagement Classifier
 This project uses machine learning to predict customer interaction with email campaigns, classifying responses into Not Opened, Opened Only, and Opened and Clicked. It includes data preprocessing, SMOTE for class imbalance, model building with Logistic Regression, Decision Tree, Random Forest, and XGBoost, and SHAP for model explainability. The XGBoost model showed the best performance and was selected as the final model to help optimize email marketing strategies.
